## 1. 使用什么工具

| 工具 | 用途 | 打开方式 |
|------|------|---------|
| **浏览器**(Chrome/Edge) | 主战场 · UI 操作 90% 场景 | 打开 http://localhost:5173/ · 登录 admin/Admin@123 |
| **Swagger UI** | 调 API(不用 Postman)· 有交互表单 | http://localhost:8080/swagger-ui/index.html · 页面上"Try it out" |
| **pg-testkit UI/API** | 造测试数据 · Mock 上下游 · 造 Eureka 假应用 | http://localhost:8081/test/health 检查 · 详见 [§6](#6-pg-testkit-测试工具怎么用) |
| **MySQL 客户端** | 看审计日志 / trace_id / interface_config 表原始数据 | MySQL Workbench / DBeaver / Navicat / `mysql -uroot -pqwe12345` · 库:`powergateway_config` |
| **lcpt-register 面板** | Eureka Server 内置 · 看谁注册了 | 浏览器 http://localhost:8091 |
| **浏览器开发者工具**(F12) | 看接口 request/response · console 报错 | F12 → Network / Console tab |
| **curl / PowerShell Invoke-WebRequest** | 极少数场景(前端不方便时)· 大部分可用 Swagger 替代 | 命令行 |
| **kill 进程**(Windows) | 端口冲突时 | 任务管理器结束进程 · 或 `taskkill /F /PID <pid>` |

**核心原则**:能在浏览器点点点搞定的 · 不用命令行。命令行只用于:启动服务 + 极个别 Swagger 未暴露的 API。

## 6. pg-testkit 测试工具怎么用

pg-testkit 是**独立测试工具**(Spring Boot 8081)· 不侵入主项目 · 主要 3 大能力:

### 6.1 3 大能力速览

| 能力 | 用途 | 访问方式 |
|------|------|---------|
| **HTTP Mock 服务器** | 模拟上下游 B 系统 · 报文按规则匹配返 mock 应答 | 主项目 `PortRoute` 配置转发到 pg-testkit 端口 |
| **TCP Socket Mock**(v0.3.0 SOCK-4) | 模拟 lcpt-host 联机 · TCP + XML_BOUNDARY 分帧 | application.yml `socket-mock.enabled=true` · 默认端口 6500 |
| **Eureka 多应用假注册**(v0.3.11 CHG-054 + v0.3.13 CHG-056) | 给 lcpt-register 塞 3 假应用供 backend discover | 见 [§6.4](#64-eureka-假应用注册手工触发) |
| **数据库直连 API** | 从 pg-testkit 查配置库/审计库 · 供 AI 或人验证 | 见 [§6.3](#63-数据库直连查询) |
| **DemoDb**(TEST-1 v1.1) | 10 表 Faker 10 万条数据 · 供接口测试用 | 前端 `/testkit/demo-db` · 或 API `POST /testkit/demo-db/init` |

### 6.2 pg-testkit 主要 API 一览

浏览器直接 GET · 或用 Swagger(pg-testkit 也开了 Swagger:http://localhost:8081/swagger-ui/index.html · 若配置了):

```
GET  /test/health                       — 健康检查
POST /test/db/query                     — 执行 SQL(body: {"db":"config|audit","sql":"..."})
GET  /test/results                      — 最近场景执行结果
POST /test/scenario/run                 — 执行内置测试场景
GET  /test/eureka/list                  — v0.3.11 · 已注册假应用列表
POST /test/eureka/register-all          — 手工全量 register 3 假应用
POST /test/eureka/register/{name}       — 单个 register
DELETE /test/eureka/deregister-all      — 全量 deregister
GET  /mock/**                           — HTTP Mock endpoint · 转 pg-testkit/src/main/resources/mocks/http/*.json
```

前端管理 UI(需 TESTER 角色 · 或数据库预置 tester 用户):

- `/testkit/demo-db` · DemoDb 管理(10 表 · 10 万数据)
- `/testkit/mock-rules` · HTTP Mock 规则
- `/testkit/mock-history` · Mock 调用历史

### 6.3 数据库直连查询

场景:验接口执行后是否写了审计日志。

用**Swagger** 或 **curl** 或 **浏览器 REST 插件**(如 Talend API Tester):

```
POST http://localhost:8081/test/db/query
Content-Type: application/json

{
  "db": "config",
  "sql": "SELECT * FROM sys_log ORDER BY id DESC LIMIT 3"
}
```

期望返 `{"rowCount":3, "rows":[...]}`。

**推荐**:直接用 **MySQL 客户端**(Workbench/Navicat/DBeaver)手工连 · 免走 pg-testkit。

### 6.4 Eureka 假应用注册(手工触发)

前置:lcpt-register(8091)已起(见 [§3.4](#34-lcpt-register-可选--联机-eureka-才需))。

**开启自动注册**:编辑 `D:/Project/powergateway/pg-testkit/src/main/resources/application.yml` · 找到:

```yaml
pg-testkit.eureka:
  enabled: false        # 改成 true
  server-url: http://127.0.0.1:8091/eureka
```

改 `enabled: true` · 保存 · 重启 pg-testkit(kill 后 mvn spring-boot:run)。

**观察**:
- 浏览器 http://localhost:8081/test/eureka/list · 应看到 registeredCount:3
- 浏览器 http://localhost:8091 (Eureka 面板)· 应看到 PG-INTERNAL/BANK-SVC/HOST-SVC 三应用
- **v0.3.13 CHG-056 加了心跳**:每 30s 自动 renew · 应用不会 evict

**手工控制**(浏览器地址栏访问 GET 即可 · POST/DELETE 用 Swagger):

- 查列表:http://localhost:8081/test/eureka/list
- 全量 re-register:用 Swagger POST /test/eureka/register-all
- 全量 deregister:用 Swagger DELETE /test/eureka/deregister-all
- 单个 register:用 Swagger POST /test/eureka/register/{name} · 如 `pg-internal`

用完记得改回 `enabled: false` · **不要 commit** 那个改动。

### 已知遗留(不影响主功能)

| 问题 | 影响 | 修复计划 |

### 常见错误 · 现场处理

| 现象 | 原因 | 手工怎么修 |
|------|------|-----------|
| 500 "Unknown column X in field list" | 老库没跑迁移 SQL | 见 [§2 环境准备](#2-环境准备) 运行 4 个 migration-*.sql |
