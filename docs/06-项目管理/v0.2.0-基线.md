- **SQLite 便携版分支**（Maven profile `db-sqlite`）→ 未做，延到 v0.3.0
- **CR-003 程序版本显示**（sys_config KV + `GET /api/app-info` + 前端底部）→ v0.3.0 backlog
- **Oracle / OceanBase 驱动预置 + Docker** → v0.3.0
