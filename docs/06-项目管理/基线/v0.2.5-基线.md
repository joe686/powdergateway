## 五、老库客户升级注意事项

**客户从 v0.2.0/v0.2.1 升级到 v0.2.5 时**:

1. **备份 dict_mapping 表**(强烈建议)
2. 执行 `backend/src/main/resources/db/migration-fn-12-scope.sql`(幂等 · 可重复执行)
3. 老数据自动 scope=3(通用共享 · 对 M1/M2 两侧都可见 · 行为兼容 v0.2.0)
4. 新增字典条目按业务侧走 `/transform/dict`(scope=1) 或 `/interface/dict`(scope=2)
5. 老 `/tools/dict` 菜单入口已下线 · 用户菜单权限自动适配 · 无需额外操作

**开发环境**:实施前 `TRUNCATE dict_mapping` 清测试数据(用户 2026-07-27 明确"现在的测试数据如果没用就删了")
