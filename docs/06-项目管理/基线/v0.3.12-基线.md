## 修复说明

### CHG-055 · EurekaRegistryClient 全 REST + RegistryClientRegistrar 自动装配

**发现路径**:v0.3.11 CHG-054 pg-testkit MultiAppSelfRegister 联机通过后 · 尝试起 backend + 建 registry_config type=eureka + curl /api/registry/discover-preview 命中 pg-testkit 3 应用 · 挖 `RegistryClientRegistrar.buildClient` 发现 case "eureka" **return null** · 说明 v0.3.9 CHG-051 加的 register REST 从未真实创建 · **死代码**。

**根因**:v0.3.9 CHG-051 只重写 register/deregister · discover 仍走 Netflix EurekaClient SDK · SDK 需 ApplicationInfoManager 装配(样板多)· Registrar 因此不装配。

**修复**:全 REST 化 · discover/heartbeat/register/deregister 都走 RestTemplate · 完全去除 Netflix SDK 依赖字段。构造函数简化为 `(config, restTemplate)` · Registrar case "eureka" 真正 `new`。

## 已知限制 · 顺延后续版本

**pg-testkit 无 heartbeat renew**:v0.3.11 CHG-054 只做了 register/deregister · Netflix Eureka 需要每 30s renew 否则 evict · 联机验证时 3 应用 30-90s 后消失 · 需 curl re-register。

**修复**:v0.3.13 minor 加 `HeartbeatScheduler` @Scheduled(30s) PUT /apps/{APP}/{instId} 续约。

**backend selfRegister IP**:自动探测取 172.18.0.1(docker0/wsl 网卡)· 用户如需 127.0.0.1 需在 SystemConfig 设置 `registry.self.ip.override=127.0.0.1`。
