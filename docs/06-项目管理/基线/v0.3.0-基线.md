**核心能力**:

| 项 | 交付内容 | 决策 |
|---|---|---|
| Netty TCP Client | 全局共享 NioEventLoopGroup(4 worker daemon)+ JVM shutdownHook + 短连接 SO_KEEPALIVE=false | Q7=A + Q20=C 短连接实装 · long/pooled 预留 |
| 三分帧编解码 | XmlBoundaryCodec(根标签自闭合 · 支持 &lt;?xml 属性顺序变体 + 无声明 + 中文根标签)· LengthPrefixCodec(4/8 字节大端头 · 剥头输出纯 payload · 默认最大 10MB) | Q5=C 三种全支持 |
| 双编码 | CharsetSupport 白名单 UTF-8 + GBK · 非白名单抛 BusinessException | Q6=B 双编码全做 |
| 依赖 | pom `io.netty:netty-all:4.1.100.Final` | Q9=A |
| ExecController 分发 | dispatchByType 加 `case "SOCKET"` · AuditContext opType=SOCKET_EXEC · 返 SocketExecResponse(rawXml + flattened + latencyMs) | — |
| interface_config schema | type VARCHAR(32) 注释扩 "SELECT/INSERT/UPDATE/DELETE/SOCKET" · config_json 加 socket 段(ip/port/framing/charset/超时/模板/prefix/connectionMode)· 幂等迁移 SQL | — |
| Eureka selfRegister | 注释更新明确"归 v0.3.2 SOCK-5-B 补齐" | Q8=A 延后 |
| FormatConverter.flattenMap | private → public static(供 SocketExecutor 复用) | backend/CLAUDE.md 关键代码地标已声明 |
