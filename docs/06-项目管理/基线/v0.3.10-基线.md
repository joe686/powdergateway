**版本编号**:v0.3.10 · **类型**:patch(bug fix only)· **主线**:v0.3.9 自主验证暴露的 2 处启动/保存阻塞 bug

## 修复说明

### CHG-052 · @Lazy 打破 Spring 循环依赖(v0.3.9 CHG-049 引入)

**症状**:v0.3.9 push 后 backend 启动失败:
```
BeanCurrentlyInCreationException: Error creating bean 'interfaceConfigService':
Requested bean is currently in creation: Is there an unresolvable circular reference?
```

**根因**:CHG-049 lifecycle hook 引入循环 InterfaceConfigService ↔ SocketInboundServerManager ↔ InboundSocketOrchestrator ↔ InterfaceConfigService。

**修复**:`@org.springframework.context.annotation.Lazy` + `@Autowired(required=false)` · 字段延迟到使用时才 resolve。

**顺带**:SysAppInfoInitializer.CURRENT_VERSION v0.3.1 → v0.3.10(v0.3.5/7/9 一直忘同步)。

### CHG-053 · SocketInboundConfig.vue 补 outbound 段 UI(v0.3.7 CHG-046 遗漏)

**症状**:自主验证 POST /api/interface/save 建 INBOUND_SOCKET 接口 · 500 "必填 outbound 段"。

**根因**:v0.3.2 SOCK-5 后端 `validateInboundSocketConfig` 强校验 outbound.applicationName/path · 但 v0.3.7 前端只写 inbound 段。

**修复**:
- outbound reactive 段 + Divider + 3 el-form-item(applicationName · path · timeoutMs)
- buildPayload 拼 outbound 到 configJson
- loadForEdit 反解 j.outbound
- doSave 前端校验 applicationName/path
