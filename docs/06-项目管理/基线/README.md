## 用途

- 记录版本发布时的：构成清单 · 测试规模 · 制品 tag · commit SHA · 覆盖的 FB/CHG
- 定基后**不再修改**任何字段（若发现描述错误,不改本文件,而在下一版本基线里备注）

## 归档规则

- 每次 `git tag -a vX.Y.Z` 前,新建 `vX.Y.Z-基线.md`,写入本目录
- 同步更新 [路线图 · 已发布表](../路线图.md#已发布) 增加一行
- 同步更新 [../README.md](../README.md) 基线列表
- 同步更新 [../../README.md](../../README.md) 顶层"当前版本"
