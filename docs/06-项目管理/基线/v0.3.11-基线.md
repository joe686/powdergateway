## 手工验收 checklist

### 前置:起 Eureka Server

用户环境需外部 Eureka Server · 3 种选择:
- **Docker**:`docker run -d -p 8761:8761 --name eureka-server steeltoeoss/eureka-server`
- **jar 直启**:下载 spring-cloud-netflix-eureka-server standalone jar
- **v0.4.0 REL-1B 后**:如果加 helm/内嵌 Server 会更方便

### 开启 pg-testkit 自注册

```yaml
# pg-testkit/src/main/resources/application.yml
pg-testkit.eureka:
  enabled: true
  server-url: http://127.0.0.1:8761/eureka
```
