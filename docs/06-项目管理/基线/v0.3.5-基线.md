## 一、交付内容

### CHG-044 · 分类型 4 页补齐(FB-057 B + FB-054 后半)

**触发**:v0.3.1 Task 5 拆下会话 · 补齐分类型 4 页 IA 一致性 · 让"高级用户直达路径"与 InterfaceWizard 能力等价。

| 页面 | 步骤数变化 | 4 项能力扩展 |
|---|---|---|
| **QueryConfig**(SELECT) | 4→6 | 字段区加字典键列 + 字段加工 step + 分库分表 step + edit 回填 + header 编辑指示 |
| **InsertConfig**(INSERT) | 3→5 | 同上 |
| **UpdateConfig**(UPDATE) | 4→6 | 同上 |
| **DeleteConfig**(DELETE) | 3→4 | edit 回填 + header + 分库分表 step(delete 无字段加工/字典键 · 场景无意义) |

**共享改造**:
- `onMounted` 加 edit 分支:`route.query.id` 有 → `getInterface(id)` 反解 form + tables + fields + conditions + processRules + shardConfigId
- `pageTitle` computed:editMode 时显示"编辑 {type}接口 #{id} · {name}"
- **字段加工 step**(简化):JSON textarea 双向绑定 processRules + 独立编辑器跳转 /convert/field-process
- **分库分表 step**(简化):shardConfigId 下拉(`listShardConfigs`) + 跳转 /interface/shard "新建"
- **字典键列**(SELECT/INSERT/UPDATE):`el-option-group` 按 systemCode 分组 · `listDictMappings scope=2` 前端聚合
- `buildConfigJson` 加 `field.dictKey` + `processRules` · `saveConfig` 加 `id` + `shardConfigId`
