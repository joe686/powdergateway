# 反馈图片

用户在反馈簿 FB-XXX 中引用的截图 / 屏幕分享 / 报错图等的目录。

## 使用约定

- **文件命名**：`FB-XXX-简短描述.png`,例如 `FB-046-亮色菜单弹窗对比.png`
- **上传位置**：直接放本目录（与本 README 同级）· 反馈簿正文用相对路径引用
- **反馈闭环后**：图片移至 [`已完成/`](./已完成/) 子目录 · 反馈簿引用路径同步更新

## 目录结构

```
反馈图片/
├── README.md          ← 本文件 · 规则说明
├── FB-XXX-XXX.png     ← 活跃反馈引用的图片
└── 已完成/            ← 反馈闭环后归档的图片
    └── README.md
```

## 引用示例

反馈簿 FB-046 里的正确写法：

```markdown
- **反馈截图**：![对比图](./反馈图片/FB-046-亮色菜单弹窗对比.png)
```

## 维护规则

由 Claude 在处理反馈簿归档时同步执行：

1. FB-XXX 状态改为 ✅/🚫/💤 后
2. 图片从 `./FB-XXX-xxx.png` 移到 `./已完成/FB-XXX-xxx.png`
3. 反馈簿正文引用路径改为 `./反馈图片/已完成/FB-XXX-xxx.png`
4. 保留图片完整历史 · 不删除 · 便于回溯反馈上下文
