  - **SOCK-5-D JSON 骨架配置示例**（v0.3.2 引入）:

    ```yaml
      responseBodyPath: "$[0].body"       # 应答业务体位置

    ```

  - **执行链路**:`ExecController` → dispatch 到 `SocketExecutor` → 渲染请求 XML → `SocketClient.send()` → 收 XML 应答 → `FormatConverter.parseXml + flattenMap` → 返回 JSON
