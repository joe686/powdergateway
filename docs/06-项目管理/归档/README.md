# 项目管理归档

已闭环的反馈/CR/待办条目归档区。**只读**（迁入后不再修改）。

## 用途

保持 [反馈簿.md](../反馈簿.md) · [待办与缺陷池.md](../待办与缺陷池.md) 主文件精简 · 只装**未做完 · 刚反馈要马上做 · 需用户确认**的活跃条目。

已闭环的条目（✅ 已交付 / 🚫 已拒绝 / 💤 已延后到已发版）迁入本目录 · 保留完整历史。
