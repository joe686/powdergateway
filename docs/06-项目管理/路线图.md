## 版本命名约定

采用 [语义化版本](https://semver.org/lang/zh-CN/)：

- `vMAJOR.MINOR.PATCH`
- **MAJOR**：不兼容的 API/配置变更（v1.0 之前允许 v0.x 破坏性变更）
- **MINOR**：新功能 / 新单元交付
- **PATCH**：Bug 修复 / 视觉修正 / 文档修正

**打 tag 命令**：

```bash
git tag -a v0.1.1 -m "PowerGateway v0.1.1 · <一句话总结>"
git push origin v0.1.1
```

**打 tag 前 checklist**（**分档，用户 2026-07-26 Q9 拍板 · B 方案**）：

| Tag 类型 | 手工测试要求 | 自动化测试要求 |
|---------|---------|---------|
| **PATCH**（vX.Y.**Z**，Bug 修复 / 文档 / 视觉修正） | 只跑 P0 冒烟约 10 条（[手工测试指南 § 一](../04-测试/v0.1.0-手工测试指南.md#一环境自检与登录p0-冒烟)） | 后端 `mvn test` 全绿 + 前端 `npm run build` 通过 |
| **MINOR**（vX.**Y**.0，新功能 / 新单元） | 跑 P0 + P1 共约 40 条（[手工测试指南 § 一 ~ 十四](../04-测试/v0.1.0-手工测试指南.md#四报文转换配置向导ux-d--m1-全链路)） | 后端 `mvn test` 全绿 + 前端 `npm run build` 通过 + 前端 vitest 关键用例 |
| **MAJOR**（**X**.0.0，破坏性变更） | 跑 P0 + P1 + P2 全量约 85 条 + 3 种目标数据库端到端 | 全套 + 端到端回归 |

**通用前置**（每类都要）：

- [ ] 涉及的 CHG-XXX 都归档到 [变更记录.md](../03-开发/变更记录.md)
- [ ] [待办与缺陷池.md](./待办与缺陷池.md) 对应条目已勾掉
- [ ] 后端 `mvn test` 全绿
- [ ] 前端 `npm run build` 通过
- [ ] 更新本文件"已发布"表
- [ ] 建 `vX.Y.Z-基线.md`（MINOR/MAJOR 必须；PATCH 可选）
