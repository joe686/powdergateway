## 阅读效率约定

**为节约上下文与人力开支：**

1. **先读本索引 + 根 CLAUDE.md**，不到需要不深入子目录
2. **反馈处理**用 [pg-feedback-flow](../.claude/skills/pg-feedback-flow/SKILL.md) skill 走固定流程，避免每次问"应该记到哪"
3. **变更登记**用 [变更记录.md](03-开发/变更记录.md) 顶部的模板，不要每次重造格式
4. **任务分解**放 `docs/03-开发/任务计划/` 下按日期命名，实施完可清（保留 CHG 引用即可追溯）
5. **不重复登记**：一件事只在一处记详细版本，其他地方用链接引用；避免两处漂移
6. **重大变更后同步索引**：每次 tag 发版 / 新增中枢文档 / CR 落地 / 归档动作后,同步更新 [本文件](README.md) · [06-项目管理/README.md](06-项目管理/README.md) · [03-开发/任务计划/README.md](03-开发/任务计划/README.md) 三处索引,防止索引与实际状态漂移（**2026-07-28 复盘落实**）
7. **归档规则**：已闭环 FB → [反馈簿-历史归档.md](06-项目管理/反馈簿-历史归档.md) · 已完成任务计划 → [任务计划/归档/vX.Y.Z/](03-开发/任务计划/归档/) · 使用过的反馈图片 → [反馈图片/已完成/](06-项目管理/反馈图片/已完成/) · 已闭环 CR → 待办与缺陷池 § "已归档 CR"
