# FN-12 × FN-09 联动设计（v0.2.0 ④）

## 一、范围（Q1/B 拍板：顺带修复 FN-09 字段行硬编码）

### 1.1 做

1. **修 FN-09 字段行渲染**：`InterfaceDocumentService.buildVisualModel()` / `buildTransformModel()` 从 `interfaceConfig.configJson.fields` / `convertTemplate.mappingRule` 读**真实字段**（当前硬编码通用示例）
2. **提取字典 key**：遍历字段级 `processRule[]` · 若 `type === 'DICT_MAP'` 取 `params.dictKey` · 否则空
3. **md/html 字段表加"字典 key"列**（Q2/A · 说明列**右侧**）：可视化接口"请求字段"+"响应字段"表 · 转换模板"字段映射"表
4. **新增 xlsx 4-sheet 单接口 endpoint**：
   - `GET /api/doc/visual/{id}/xlsx` · `GET /api/doc/transform/{id}/xlsx`
   - 可视化接口 4 sheet：**基本信息 / 请求字段（含字典 key）/ 响应字段（含字典 key）/ 字典对照**（Q4/A · spec 原话）
   - 转换模板 4 sheet：**基本信息 / 字段映射（含字典 key）/ 保留空 or 隐藏 / 字典对照** —— 实际 3 sheet（"响应字段" sheet 转换模板无对应，跳过第 3 sheet 或改为**基本信息 / 字段映射 / 字典对照** 共 3 sheet）
5. **升级 zip 打包**：`exportAllVisualZip` / `exportAllTransformZip` 每接口 **md + html + xlsx** 3 份 · `manifest.json.entries[]` 加 `xlsx` 键
6. **前端 UI**：`InterfaceDocument.vue` 行内加**独立"下载 Excel"按钮**（Q3/A · 3 独立按钮）· `api/interfaceDoc.js` 加 xlsx endpoint · `download*Zip` 无需改（后端自动包含 xlsx）
7. **测试**：后端新增 8-10 用例（真实字段提取 · 字典 key 提取 · xlsx 4-sheet 生成 · 字典对照去重汇总 · zip 3 份含 manifest xlsx 键）· 前端 vitest 2-3 用例（按钮存在 · xlsx 下载调用）

### 1.2 不做

- 前端字段/字典关系 UI 展示（如接口详情页看到"此字段用了字典 X"）— 归 v0.3.0+
- Excel 里字典对照 sheet 的编辑能力（只导出，不导入编辑）
- xlsx 模板样式定制（用 `ExcelExportUtil` 通用样式，灰底加粗表头）

## 二、后端改造

### 2.1 `InterfaceDocumentService.java`

**新增或改造**：
- `buildVisualModel(id)` 从 `interfaceConfig.configJson` 读真实 `fields` 列表（含 name/type/required/desc + `processRules`）
- `buildTransformModel(id)` 从 `convertTemplate.mappingRule` 读真实字段映射（含源/目标字段 + `processRule`）
- 新增私有 `extractDictKey(List<ProcessRule> rules)` 返 `String`（第一条 DICT_MAP 的 dictKey · 无则 null）
- `renderMarkdown()` / `renderHtml()` 字段表 header + row 追加"字典 key"列（说明列右侧）
- 新增 `buildVisualXlsx(id)` / `buildTransformXlsx(id)` 返 `byte[]`（4 sheet）
- 修改 `exportAllVisualZip / exportAllTransformZip`：每接口加 xlsx · manifest.entries 加 `xlsx` 字段

### 2.2 字典对照 sheet 数据源

- 遍历本接口所有字段的 processRules · 收集所有 `{system, dictKey, direction}` 三元组去重
- 对每个三元组调 `dictMappingMapper.selectByLookup(system, dictKey, direction)` 拿全量条目
- 组装成 sheet 行：`system | dictKey | direction | source_value | target_value | cn_label`

### 2.3 `InterfaceDocumentController.java`

新增 2 endpoint：
- `GET /api/doc/visual/{id}?format=xlsx` 或独立路径 · 返 `ResponseEntity<byte[]>` 复用 `InterfaceConfigController.excelResponse` helper
- `GET /api/doc/transform/{id}?format=xlsx` 同上

**推荐扩展现有 endpoint 的 `format` 参数支持 xlsx**（对齐 md/html 现有模式），无需新增独立路径。

## 三、前端改造

### 3.1 `api/interfaceDoc.js`

`downloadTransformDoc(id, format)` / `downloadVisualDoc(id, format)` 现已接受 format 参数 · 传 `'xlsx'` + `responseType: 'blob'` 即可。**若既有实现只支持 md/html**（无 blob 响应），补一层判断加 blob。

### 3.2 `InterfaceDocument.vue`

- 行内操作列追加第 3 按钮 `<el-button @click="download(row.id, 'xlsx')">Excel</el-button>`
- 顶部"全量导出 zip"按钮无需改（后端自动含 xlsx）
