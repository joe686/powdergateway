## 一、现状分析

`frontend/src/views/LoginView.vue` 当前样式（`105-158` 行）：

- 背景：`linear-gradient(135deg, #001529 → #0066cc)` 深蓝硬渐变 —— **与 UX-A 全站视觉基座（浅色/深色毛玻璃 + 柔和 blob 背景 + 星野）不一致**
- 卡片：白色纯色 `#fff` + `border-radius: 12px` —— **未使用 `--pg-glass-*` token**
- Logo：单色 `#1890ff` 图标 —— **未使用品牌渐变色 `--pg-primary-grad`**
- 未支持深色模式（`data-theme="dark"` 切换后仍是硬渐变）

UX-A 已提供的设计 token（`frontend/src/styles/tokens.css`）：

| Token | 用途 |
|-------|------|
| `--pg-bg-base` + `--pg-bg-blob-1/2/3` | 全站背景基色 + 3 团 blob（模糊椭圆装饰） |
| `--pg-glass-bg` / `--pg-glass-border` / `--pg-glass-blur` / `--pg-glass-shadow` | 毛玻璃卡片 |
| `--pg-primary-grad` | 品牌渐变（蓝紫） |
| `--pg-text-primary` / `--pg-text-secondary` | 文本色阶 |

## 二、目标视觉规范

1. **背景**：`--pg-bg-base` 铺底 + 3 个 `filter: blur(80px)` blob 定位在四个象限做柔光（复用 `MainLayout` 的 blob 组件或复制其样式片段）
2. **卡片**：毛玻璃 —— `background: var(--pg-glass-bg)`, `backdrop-filter: blur(var(--pg-glass-blur))`, `border: 1px solid var(--pg-glass-border)`, `box-shadow: var(--pg-glass-shadow)`
3. **Logo 区**：图标用 `background: var(--pg-primary-grad); -webkit-background-clip: text; color: transparent` 做渐变字/渐变图标；标题用同一渐变
4. **深色模式**：完全靠 token 切换，不写重复 CSS —— 只要引用 token，`data-theme="dark"` 自动生效
5. **移动响应**：卡片 max-width 400px + `padding: 5vw`，`min-height: 100vh` + `align-items: center`
6. **按钮**：主按钮沿用 element-plus-override 里已定义的圆角与渐变（如已有），或用 `background: var(--pg-primary-grad)` 覆写
