# v0.5.0 · FN-BIZ 业务菜单生成能力 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现"接口 → 业务菜单 → 可运行页面"的一键生成能力：4 类 CRUD 接口经生成中心一键转为可执行业务菜单，业务用户点菜单进通用页面即调用底层接口。含全链路监控（trace_id 串四表）+ 独立可裁剪子模块。

**Architecture:** 新建独立 Maven 子模块 `pg-biz-menu`（对齐 pg-testkit 模式），通过 `@ConditionalOnProperty(biz.menu.enabled)` 装配。业务菜单复用 SYS-3 升级后 `sys_menu` 表（origin=BIZ/BIZ_APP），不新建菜单表。执行入口 `POST /api/biz/exec/{menuId}` 生成 trace_id 塞 ThreadLocal，转发到现有 `POST /api/exec/{interfaceId}`；SqlAuditAspect / SysLogAspect / PerfStatAspect 读取 trace_id 写入自身表；新表 `business_op_log` 存请求响应报文。前端一套通用 `BusinessInterfacePage.vue` 覆盖所有业务菜单，按接口元数据运行时渲染。

**Tech Stack:** Spring Boot 2.7 / MyBatis-Plus / Sa-Token / Snowflake ID / Vue 3 / Element Plus / ECharts / Pinia / vue-draggable-next

## Global Constraints

- 所有对话/代码注释/commit message 用**中文**
- 测试类必须加 `@ActiveProfiles("test")`
- TDD 三步不可跳：Red → Green → Refactor
- 一 Task 一 commit，格式 `feat(FN-BIZ): FB-041 <一句话>`
- **裁剪原则**：`biz.menu.enabled=false` 时后端所有 Bean 不注册、API 404，前端组件 v-if 隐藏、路由不注册。发版前必测项。
- **强依赖**：SYS-3 升级实施必须先完成（本计划 Task 5 起假设 sys_menu / sys_role_menu 等表已就位）
- 数据库脚本放 `backend/src/main/resources/db/upgrade/v0_5_0/`
- 业务应用节点复用 sys_menu 表 origin=BIZ_APP，不建 business_app 独立表
- business_op_log 放**配置库**（默认数据源，不走 `@DS("audit")`）
- 复用现有：`InterfaceConfigService`（M2-7 接口）、`POST /api/exec/{id}`（M2-7 执行入口，本计划不修改）、`DictMappingProcessor`（FN-12）、`QueryCacheManager`（M2-10）、三 Aspect（M2-9/SYS-1/SYS-2，需读 trace_id）、`ConditionBuilder.vue`（M2-3）、`DashboardView.vue`（AUX-2）
- 后端测试增量目标 +45~65 用例，前端 +15 用例

```java
@Service @RequiredArgsConstructor
public class BusinessMenuGeneratorService {
    private final InterfaceConfigService interfaceService;
    private final InterfaceMetadataExtractor extractor;
    private final SysMenuMapper menuMapper;
    private final ApplicationEventPublisher events;
    private final ObjectMapper om = new ObjectMapper();

    @Transactional
    public List<GenerateResult> generate(List<Long> interfaceIds, Long appMenuId, Long groupMenuId) {
        List<GenerateResult> results = new ArrayList<>();
        for (Long ifaceId : interfaceIds) {
            try {
                InterfaceConfig cfg = interfaceService.getById(ifaceId);
                String hash = extractor.computeHash(cfg);
                SysMenu existing = findByInterfaceAndApp(ifaceId, appMenuId);
                if (existing != null) {
                    existing.setMetadataHash(hash);
                    existing.setStatus("NORMAL");
                    menuMapper.updateById(existing);
                    results.add(GenerateResult.ok(ifaceId, existing.getId()));
                } else {
                    SysMenu m = buildDefaultMenu(cfg, appMenuId, groupMenuId, hash);
                    menuMapper.insert(m);
                    results.add(GenerateResult.ok(ifaceId, m.getId()));
                }
            } catch (Exception ex) {
                results.add(GenerateResult.fail(ifaceId, ex.getMessage()));
            }
        }
        events.publishEvent(new MenuGeneratedEvent(this, results));
        return results;
    }

    private SysMenu buildDefaultMenu(InterfaceConfig cfg, Long appId, Long groupId, String hash) {
        SysMenu m = new SysMenu();
        m.setCode("biz." + appId + "." + cfg.getName());
        m.setName(defaultChineseName(cfg));  // Task 18 落地
        m.setIcon(defaultIcon(cfg.getType()));
        m.setParentId(groupId != null ? groupId : appId);
        m.setType("PAGE");
        m.setOrigin("BIZ");
        m.setBadge("[业务]");
        m.setBadgeColor("success");
        m.setRoutePath("/biz/menu/" + cfg.getId());
        m.setComponent("features/biz-menu/BusinessInterfacePage.vue");
        m.setInterfaceId(cfg.getId());
        m.setAppMenuId(appId);
        m.setStatus("NORMAL");
        m.setMetadataHash(hash);
        m.setIsBuiltin(0);
        m.setVisible(1);
        return m;
    }
}
```

```java
@Component @RequiredArgsConstructor
public class MenuStatusSyncListener {
    private final SysMenuMapper menuMapper;
    private final InterfaceConfigService interfaceService;
    private final InterfaceMetadataExtractor extractor;

    @Async
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onChanged(InterfaceConfigChangedEvent e) {
        if (e.getChangeType() != ChangeType.FIELD_MODIFIED) return;
        InterfaceConfig cfg = interfaceService.getById(e.getInterfaceId());
        String newHash = extractor.computeHash(cfg);
        menuMapper.selectList(qw -> qw.eq("interface_id", e.getInterfaceId()))
            .forEach(m -> {
                if (!newHash.equals(m.getMetadataHash())) {
                    m.setStatus("EXPIRED");
                    menuMapper.updateById(m);
                }
            });
    }
}
```

```java
@Service @RequiredArgsConstructor
public class BusinessInterfaceInvokerService {
    private final SysMenuMapper menuMapper;
    private final InterfaceExecutor executor; // M2-7 已有
    private final BusinessOpLogService opLogSvc;

    public Result<?> invoke(Long menuId, Map<String, Object> body) {
        SysMenu menu = menuMapper.selectById(menuId);
        if (menu == null || !"BIZ".equals(menu.getOrigin()))
            throw new BusinessException(404, "菜单不存在");
        if ("DISABLED".equals(menu.getStatus()) || "ORPHAN".equals(menu.getStatus()))
            throw new BusinessException(400, "菜单不可用（" + menu.getStatus() + "）");

        String traceId = TraceIdContext.generate();
        TraceIdContext.set(traceId);
        long start = System.currentTimeMillis();
        try {
            Result<?> resp = executor.exec(menu.getInterfaceId(), body);
            long elapsed = System.currentTimeMillis() - start;
            opLogSvc.recordAsync(traceId, menu, body, resp, elapsed);
            return resp;
        } finally {
            // TraceIdContext.clear() 由 Filter 兜底，此处不清避免 async 落库时读不到
        }
    }
}
```
